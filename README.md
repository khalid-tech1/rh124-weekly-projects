# RH124 Weekly Projects

This repository contains my weekly hands-on Linux administration projects based on Red Hat RH124 concepts.

The projects are designed to combine:

- Red Hat-style lab practice
- Real-world Linux administration scenarios
- Command-line troubleshooting
- File and directory management
- Users and groups
- Permissions and ownership
- Redirection and pipelines
- Links and filesystem management

Each weekly project includes:

- Project instructions
- Solutions for later review
- Verification results
- Notes about mistakes and corrections
